## ⚙️ Конфигурация

### Настройки бота (`config.py`)

```python
BOT_TOKEN = os.getenv("BOT_TOKEN")  # Токен бота
ADMIN_ID = 4324231523               # ID главного администратора
ADMIN_ID_2 = 5343425324            # ID второго администратора
ADMIN_IDS = [5343425324]
CONTACT_USERNAME = "...."          # Username для связи
```

### Настройка букетов (`data/bouquets.yaml`)

```yaml
bouquets:
  - id: "b1"
    name: "Синие розы"
    base_price: 4500
    image_path: "images/1.jpg"
    is_popular: true
    order_count: 0
    quantities:
      - value: 21
        multiplier: 0.244  # 21 роза = 1100₽
      - value: 51
        multiplier: 0.511  # 51 роза = 2300₽
      - value: 71
        multiplier: 0.711  # 71 роза = 3200₽
      - value: 101
        multiplier: 1.0    # 101 роза = 4500₽
    packaging:
      - type: "standard"
        name: "Стандартная"
        price: 0
      - type: "premium"
        name: "Премиум"
        price: 300
      - type: "black"
        name: "Чёрная"
        price: 500
```

## 🎯 Возможности бота

### Путь покупателя

1. **Запуск:** команда `/start`
2. **Каталог:** просмотр всех доступных букетов
3. **Выбор букета**
4. **Настройка заказа:**
   - Количество роз: 21, 51, 71 или 101
   - Упаковка: Стандартная, Премиум или Чёрная
   - Опционально: Экспресс-доставка (+1000₽)
   - Опционально: Открытка (+100₽)
   - Дата доставки (минимум 2–4 дня в зависимости от количества)
   - Время (12:00 — 20:00)
   - Способ получения: самовывоз или встреча в городе
5. **Добавление в корзину:** просмотр и подтверждение
6. **Связь с продавцом для оплаты**

### Команды администратора

- `/admin` — открыть админ-панель
- `/cancel` — отменить текущее действие

## 🎨 Кастомизация

### Добавление нового букета

1. **Через админ-панель:**
   - Команда `/admin`
   - Нажать «➕ Добавить букет»
   - Следовать инструкциям

2. **Вручную в `data/bouquets.yaml`:**
   - Скопировать структуру существующего букета
   - Изменить `id`, `name`, `base_price`, `image_path`
   - Загрузить фото в папку `images/`

### Добавление администраторов

Отредактировать `data/admins.yaml`:
```yaml
admins:
  - 1063802362
  - id_нового_администратора
```

И обновить `config.py`:
```python
ADMIN_IDS = [1063802362, id_нового_администратора]
```
